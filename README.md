# PokerNow Analyst 11

Windows-приложение и расширение Opera/Chromium для анализа PokerNow.

[Скачать последний релиз](https://github.com/hsvea/pokernow-analyst/releases/latest).
Для первой установки запустите `PokerNowSetup.exe`; если уже установлена 8.1,
нажмите «Проверить обновления» в приложении.

- v9: balanced sampling, покрытие пар и ESS, сравнение с systematic.
- v10: префлоп-подсказки и ручное уточнение ситуации в оверлее.
- v11: профили по PokerNow ID, история ников, заметки и VPIP/PFR в оверлее.
- GitHub Releases: фоновая проверка, SHA-256, отдельный updater, backup и rollback.
- Официальный Codex SDK и его runtime включены в EXE; вход через ChatGPT выполняется отдельно.

Исходной основой служит найденный архив v8. Последующие функции реализованы заново
по доступному README v9 и сохранившимся сообщениям исходного чата.
Это не побайтовое восстановление недоступных архивов v9–v11.
