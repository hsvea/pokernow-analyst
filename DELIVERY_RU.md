# Установка и обновления PokerNow Analyst

Эта ветка восстановлена из целого локального архива v8. Версия 8.1.0 добавляет
доставку через GitHub; она не выдаётся за отсутствующую v11.

## Первая установка

1. Скачайте PokerNowAnalyst-Windows.zip из согласованного GitHub Releases.
2. Закройте старое приложение. Откройте в Проводнике `%LOCALAPPDATA%`.
3. Создайте папку `PokerNowAnalystApp`, распакуйте в неё ZIP. Внутри должны
   находиться `app`, `pokernow_overlay_v2` и `bundle.json`, без лишней вложенной папки.
4. Запустите `app\PokerNowAnalyst.exe`. Можно создать ярлык на этот файл.
5. В `opera://extensions` отключите старый оверлей и один раз загрузите распакованное
   расширение из `%LOCALAPPDATA%\PokerNowAnalystApp\pokernow_overlay_v2`.
6. Введите код сопряжения приложения в расширение.

История и настройки находятся в `%APPDATA%\PokerNowAnalyst`. Установка и обновление
не переносят и не очищают эту папку. Старые копии приложения должны быть закрыты.

## Следующие обновления

Проверка при запуске выполняется в фоне. Доступная версия отображается внизу окна
и на вкладке «Подключение и безопасность», без модального окна. Там же есть кнопки
«Проверить обновления» и «Установить обновление». Установка требует подтверждения.
Ошибки сети при автоматической проверке не прерывают работу; ручная проверка показывает ошибку.

Загрузка идёт из публичного GitHub Releases. Проверяются стабильная версия, точный
репозиторий и имя файла, размер, SHA-256 от GitHub, состав ZIP и версия расширения.
Это защита целостности и привязка к доверенному аккаунту GitHub, не отдельная цифровая
подпись издателя. GitHub-токены в приложение не входят.

Обновлятор ждёт завершения приложения, сохраняет резервную копию SQLite через
SQLite backup API и настройки, затем меняет обе папки. При занятых файлах повторяет
операцию до 15 секунд. Если замена не удалась, возвращает прежние компоненты.
После запуска новая версия должна подтвердить готовность за 60 секунд; иначе
обновлятор возвращает прежние бинарники и запускает их. База не мигрируется этим
выпуском. Будущие изменения схемы должны сохранять совместимость для отката.

Расширение нужно перезагрузить кнопкой Reload в Opera и обновить вкладку стола.
Путь расширения остаётся прежним. Автоматическая перезагрузка расширения не обещается.

## Восстановление после сбоя питания или блокировки файлов

Резервные копии: `%LOCALAPPDATA%\PokerNowAnalystApp\backups`.
Журналы обновления: `%APPDATA%\PokerNowAnalyst\updates\update-*\error.txt`.
Закройте приложение и Opera. Сохраните текущую папку установки, затем восстановите
`app`, `pokernow_overlay_v2`, `bundle.json` из последней полной резервной копии.
Папка `userdata` содержит копии базы и настроек. Восстанавливайте их только вручную
при необходимости, с закрытым приложением, предварительно сохранив текущую папку данных.
При прерывании питания между заменами может потребоваться это ручное восстановление.

## Публикация для разработчика

Укажите подтверждённый `owner/repository` в release_config.py. Для каждого выпуска
увеличивайте VERSION (три числа). Сначала выполните тесты и Windows-сборку.
Коммит и тег `v<VERSION>` запускают GitHub Actions. Workflow собирает два EXE,
проверяет ZIP, загружает артефакты в черновик Release и только затем публикует его.
Токен берётся из GitHub Actions и используется только там. Не перезаписывайте
опубликованные версии. Защитите основную ветку и теги, включите 2FA для GitHub.

Локально: Python 3.12+, `python -m pip install pyinstaller==6.16.0`,
`python -m unittest discover -s tests -v`, `python build_release.py`.
Windows EXE не подписаны сертификатом; Windows может показать SmartScreen.
