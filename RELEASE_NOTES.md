# PokerNow Analyst v14.0.1

- Исправлено автоматическое определение позиции по отдельной фишке дилера PokerNow (`dealer-button-ctn / dealer-position-N`).
- Позиция Hero видна рядом с картами и после флопа; в префлопе указан источник «по фишке дилера».
- Пустые места пропускаются, сфолдившие игроки сохраняют позицию, ожидающие следующей раздачи исключены из расчёта. Для двух игроков дилер — SB.
- Исправлено чтение видимых статусов Fold / In Next Hand / Away.
- При отсутствующей, неоднозначной фишке или неизвестном месте позиция не выдумывается. Ручная поправка префлопа остаётся доступна.

Обновление: «Проверить обновления» → «Установить обновление», затем Reload расширения (если оно не перезагрузилось автоматически) и обновление страницы стола. LOG / LEDGER для определения позиции не нужен.
