# PokerNow Analyst v15.0.2

- Windows-вкладка «Игроки за столом» теперь по умолчанию показывает наблюдения со стола: число частичных наблюдений рук, действия Call / Raise / Bet / Check / Fold и изменения ставки без распознанного действия.
- VPIP/PFR/3-bet/Fold vs 3-bet/AF находятся в отдельном источнике «Полные руки (LOG / CSV)». В режиме «Со стола» пустые столбцы этих показателей больше не мешают чтению собранных данных.
- Под таблицей и над ней объяснено различие между частичными наблюдениями и полными историями. Прочерки не заменяются вымышленными процентами.

Обновитесь через «Проверить обновления». Ранее собранные наблюдения сохраняются и сразу отображаются в новом режиме. Исправление префлоп-подсказки и компактные проценты из 15.0.1 включены.
