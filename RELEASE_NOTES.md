# PokerNow Analyst v15.1.0

- Флоп, тёрн и ривер: отдельный видимый блок решения в компактном режиме. Показывает CHECK либо сравнение equity с ценой колла и пояснение процентов.
- Это ориентир против случайных рук, не GTO: диапазоны ставки соперника, рейк и будущие ставки могут изменить решение. Сайзинг ставки без этих данных не выдумывается.
- Префлоп: последовательные повышения распознаются по изменениям ставок стола без LOG — рейз, 3-бет, 4-бет. Уже внесённая ставка Hero не вызывает повторного совета повысить.
- Исправлено изменение размера BB после повышения игроком на большом блайнде.
- При подключении посреди повышений, пропуске наблюдений или неоднозначных изменениях оверлей объясняет нехватку данных. Для автоматического распознавания оставьте стол открытым с начала следующей раздачи.

Обновитесь через «Проверить обновления», перезагрузите расширение и вкладку стола. В заголовке оверлея должно появиться v15.1.0. База и настройки сохраняются.
