PokerNow Analyst 8.1.0 — восстановлено из проверенного исходного архива v8.

Добавлены фоновая проверка GitHub Releases, ручная проверка и установка обновлений,
проверки SHA-256 и структуры ZIP, отдельный Windows updater, резервное копирование
и откат бинарников при неудачном запуске. Данные остаются в APPDATA.

Это продолжение доступной v8, не восстановленный архив v11. Ранее заявленные
новые возможности v9–v11 в этот выпуск не входят.

После установки обновления нажмите Reload у расширения в opera://extensions
и обновите страницу стола. Первая установка описана в DELIVERY_RU.md.
