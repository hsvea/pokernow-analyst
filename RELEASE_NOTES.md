# PokerNow Analyst v14.0.0

- В оверлее появились вкладки «Раздача» и «Игроки». Во второй — только текущий состав стола: руки, VPIP, PFR, 3-bet, Fold vs 3-bet, AF и видимый статус.
- Сортировка по нику, рукам и VPIP; фильтр «Только в раздаче» по видимому статусу. Без фильтра сфолдившие и временно отсутствующие участники остаются, пока занимают место.
- Клик по игроку открывает историю ников, заметку и знаменатели показателей. Отмечается малая выборка, а отсутствие возможностей показывается как «—», а не 0%.
- В Windows добавлена вкладка «Игроки за столом» с переходом в существующий редактор заметок. Состав обновляется; спустя 8 секунд без снимков список скрывается. При нескольких вкладках показан последний приславший снимок стол.
- При отсутствии свежего ответа приложения оверлей показывает состав, но скрывает старые проценты. Статистика привязана к PokerNow ID; без ID — только к нику.

Статистика строится по всем импортированным завершённым раздачам этих игроков, не только по текущему столу. Типы игр в существующей базе не разделены. Наблюдения за столом не прибавляются к числу рук. Для заполнения процентов импортируйте CSV истории и включите передачу данных из оверлея.

Обновление: «Проверить обновления» → «Установить обновление», затем обновление страницы стола; при необходимости Reload расширения. Для таблицы игроков открытый LOG / LEDGER не требуется.
