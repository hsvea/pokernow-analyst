# PokerNow Analyst v11.0.0

Восстановлены описанные функции v9–v11 поверх настоящих исходников v8:

- Balanced sampling, покрытие пар/массы и ESS, сравнение на двух seed.
- Префлоп-подсказки с размерами и ручной корректировкой неизвестной ситуации.
- Постоянный профиль по PokerNow ID, история ников, заметки, VPIP/PFR/hands в оверлее.
- Установщик PokerNowSetup.exe, единое обновление приложения и расширения через GitHub.
- Codex SDK и CLI включены в Windows EXE; вход через ChatGPT выполняется отдельно.

Для первой установки запустите PokerNowSetup.exe с подключением к интернету.
Из 8.1.0: «Проверить обновления» → «Установить обновление», затем Reload расширения
в opera://extensions и обновление вкладки стола. Начиная с расширения v11 предусмотрена
попытка автоматического Reload после следующих обновлений; ручной Reload остаётся доступен.
Кнопка установки скачанного ZIP тоже сверяет файл с текущим релизом GitHub через интернет.

Данные остаются в APPDATA. Миграция базы только добавляет таблицы и сохраняет
совместимость с v8 для отката. Резервные копии создаются перед заменой компонентов.

Это реконструкция по доступным описаниям, не найденные архивы v9–v11.
Префлоп — эвристика, не GTO solver. Живой стол и реальный вход Codex требуют проверки
в пользовательском окружении. EXE не подписаны сертификатом издателя.
