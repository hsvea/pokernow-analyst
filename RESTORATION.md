# Основания восстановления v11

Доступен настоящий `PokerNowAnalyst_GTO_Windows_v8_Codex.zip`, сохранённый README v9
и последние сообщения чата «PokerNow game tab» (6ae53d5e-a254-83ed-b758-85a73ef0683c).
Полные архивы и исходники v9–v11 не найдены. Версия 11.0.0 — новая реализация
описанных изменений поверх v8, а не утверждение о восстановлении каждого старого байта.

| Этап | Доступное описание | Реализация |
|---|---|---|
| v9 | balanced q=.6p+.4/N, p/q, покрытие/ESS, 80 комбинаций, два seed | multistreet_solver.py, multistreet_ui.py, benchmark_v9.py |
| v10 | префлоп 2–10 игроков, позиция, лимп/raise/3bet/4bet, размеры, ручные поправки | pokernow_overlay_v2/preflop.js, content.js |
| v11 | ID и история ников, заметки, VPIP/PFR/hands в оверлее | profiles.py, core.py, app.py, content.js |
| Доставка | GitHub, стабильная папка, обновление при запуске/по кнопке, backup | updates.py, updater.py, update_ui.py, installer.py, release workflow |

Префлоп с адаптацией диапазонов по профилю оппонента в доступном чате был предложением
следующего шага; здесь он не выдается за выполненную часть v11. Текущие подсказки
используют эвристические диапазоны, а статистика показывается отдельно.

Старые результаты benchmark не копировались: JSON в examples содержит новые измерения.
Перезагрузка unpacked extension зависит от браузера: предусмотрена попытка runtime.reload
после смены файлов и ручной Reload как обязательный доступный резервный вариант.
