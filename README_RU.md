# PokerNow Analyst 14 — функции

Сохранены возможности исходной v8: импорт CSV PokerNow, локальная статистика и заметки,
анализ river/postflop/multistreet CFR+, проверки качества и разбор через Codex.
Все рекомендации требуют проверки человеком; приложение не нажимает игровые кнопки.

## v9 — покрытие приватных пар

Добавлен balanced sampling: q = 0.6p + 0.4/N. Поправка p/q используется для regrets
и усреднения стратегии. Systematic остаётся вариантом по умолчанию. Лимит диапазона
увеличен до 80 комбинаций, лимит узлов остаётся 230000. Отчёт содержит число посещённых
пар, покрытие целевой вероятностной массы и ESS по весам. ESS не доказывает независимость
выборки или близость стратегии к равновесию. Кнопка «Покрытие v8 / v9» сравнивает оба
способа с одинаковым числом миров на двух seed; exact enumeration отключён.
Новый воспроизводимый пример: `python benchmark_v9.py`, результаты в
`examples/v9_coverage_reconstructed.json`. Это новые измерения, не старые цифры v9.

## v10 — префлоп в оверлее

Учитываются две карты героя, 2–10 игроков, позиция, BB, лимперы, текущая ставка,
сценарий unopened/limped/raise/3bet/4bet и эффективный стек. Выводятся Fold, Check,
Call, Raise, 3-Bet или 4-Bet с размером. Размер повышения — итоговая ставка героя,
не добавочная сумма. Сильные руки на коротком стеке могут получить рекомендацию all-in.

Это эвристические диапазоны, а не префлоп GTO solver. Рейк, анте, точные диапазоны
оппонентов и все особенности multiway не моделируются. Неполная история повышений
не угадывается: раскройте ручные настройки и укажите сценарий. Там же можно исправить
BB, позицию, число игроков/лимперов, ставку, вклад героя и стек. Позиция определяется
автоматически только при доступном маркере дилера и номерах мест. Изменение DOM PokerNow
может потребовать ручного ввода. Ситуация сбрасывается при смене карт/борда; при повторе
тех же карт в новой раздаче используйте кнопку сброса.

## v11 — личности игроков

Основной ключ — PokerNow profile ID. При смене ника сохраняются история имён, статистика
и заметка. Одинаковые ники разных ID не объединяются. Если сайт не дал ID, используется
ник; такие записи не объединяются с ID автоматически. Старые записи базы сохраняются,
новые таблицы добавляются без удаления прежних. Оверлей показывает известные имена,
заметку, число рук и VPIP/PFR. Статистика считается по импортированным завершённым рукам,
а не по числу снимков стола; при отсутствии рук проценты не подменяются нулями.
Передача снимков в локальное приложение включается пользователем с кодом сопряжения.

## Codex и обновления

Windows-сборка содержит официальный `openai-codex==0.163.0` и CLI runtime.
Вход через ChatGPT выполняется отдельно. Сборка проверяет импорт SDK и запуск CLI
`--version`, не выполняя вход или платный запрос модели. Реальная авторизация и ответы
модели в этой проверке не тестировались. Официальная документация:
https://learn.chatgpt.com/docs/codex-sdk

Установка, обновление, сохранение данных и откат описаны в DELIVERY_RU.md.
Проверки оверлея используют воспроизводимый тестовый стол; совместимость с текущим
живым столом PokerNow требует проверки в браузере пользователя.


## v12 — оверлей

- Компактный блок действия, размера и объяснения. Полный расчёт equity раскрывается кнопкой «Подробнее».
- Видимая ситуация: BB, позиция, число игроков, остаток эффективного стека, ставка, вклад героя, лимперы и сценарий. Ручные значения отмечаются отдельно; неизвестные данные не скрываются.
- История ников и заметка открываются нажатием на панель игрока. При числе рук меньше 50 видна отметка «Малая выборка»; это предупреждение, не статистический порог надёжности.
- Масштаб 80/100/120%, перетаскивание, сворачивание и сохранение вида. Кнопка ↺ возвращает панель в окно.
- Сброс ручных поправок при смене карт, ID раздачи (если доступен), дилера, стола или очистке борда. Скрытая вкладка, сброшенные карты героя и отсутствие изменений стола более 90 секунд приостанавливают подсказки.
- Статус Windows всегда виден; устаревший ответ профилей не отображается. Расчёт equity использует текущие суммы банка и колла после завершения.

Обновление: «Проверить обновления» в Windows-приложении → «Установить обновление».
После установки обновите страницу стола; если старая панель осталась, нажмите Reload у расширения в opera://extensions.

Префлоп остаётся эвристикой, не GTO. Данные читаются из видимого DOM. При отсутствии номера раздачи и внешних изменений невозможно отличить новую раздачу с теми же картами — используйте «Сбросить ситуацию». Пауза после 90 секунд без изменений является предосторожностью, а не доказательством разрыва соединения PokerNow. Заметки редактируются в Windows-приложении. Проверки выполняются на тестовом столе; текущий живой DOM PokerNow может отличаться.


## v13 — журнал и диагностика

- Чтение открытого Session Log по структуре, проверенной на живом столе PokerNow. История блайндов, лимпов, повышений, коллов и фолдов выводится в оверлее.
- Автоматическое определение raise / 3-bet / 4-bet, лимперов, BB, цены колла и открывшегося игрока при согласованной истории. Для автоподсказки ожидается ход Hero. Ручные поправки имеют приоритет.
- Архивная раздача, отсутствующее начало, неизвестные строки, неполный all-in raise и расхождение со ставками/бордом блокируют автоматическое использование журнала. «Начало видно · сверено» означает сверку доступных строк, а не гарантию отсутствия пропущенных событий на стороне сайта.
- Исправлена опасная несовместимость: на PLO/PLO5 и при неизвестном типе игры Hold’em-подсказки и equity отключены. Все видимые карты Hero сохраняются, вместо обрезки до первых двух. Omaha solver в этот выпуск не входит.
- «Ошибка распознавания»: предпросмотр и локальное сохранение обезличенного JSON. Ники, ID, URL стола, карты, заметки, сырой журнал и код сопряжения не включаются. Ничего автоматически не отправляется.

Обновитесь через «Проверить обновления», затем Reload расширения при необходимости и обновление вкладки PokerNow. Для чтения истории откройте LOG / LEDGER на текущей раздаче. PokerNow может оставить окно на старой раздаче: вернитесь к последней стрелкой «« Hand #…» или переоткройте журнал. Расширение не нажимает эти и игровые кнопки за пользователя.

Проверена реальная структура Session Log на PLO5-столе; функциональные сценарии NL Hold’em, смены раздач и отказов проверены на обезличенных искусственных примерах. Точное распознавание всех разновидностей журналов не обещается. Анте, straddle и неполные повышения требуют ручного разбора.


## v14 — игроки за столом

- В оверлее появились вкладки «Раздача» и «Игроки». Во второй — только текущий состав стола: руки, VPIP, PFR, 3-bet, Fold vs 3-bet, AF и видимый статус.
- Сортировка по нику, рукам и VPIP; фильтр «Только в раздаче» по видимому статусу. Без фильтра сфолдившие и временно отсутствующие участники остаются, пока занимают место.
- Клик по игроку открывает историю ников, заметку и знаменатели показателей. Отмечается малая выборка, а отсутствие возможностей показывается как «—», а не 0%.
- В Windows добавлена вкладка «Игроки за столом» с переходом в существующий редактор заметок. Состав обновляется; спустя 8 секунд без снимков список скрывается. При нескольких вкладках показан последний приславший снимок стол.
- При отсутствии свежего ответа приложения оверлей показывает состав, но скрывает старые проценты. Статистика привязана к PokerNow ID; без ID — только к нику.

Статистика строится по всем импортированным завершённым раздачам этих игроков, не только по текущему столу. Типы игр в существующей базе не разделены. Наблюдения за столом не прибавляются к числу рук. Для заполнения процентов импортируйте CSV истории и включите передачу данных из оверлея.

Обновление: «Проверить обновления» → «Установить обновление», затем обновление страницы стола; при необходимости Reload расширения. Для таблицы игроков открытый LOG / LEDGER не требуется.


# PokerNow Analyst v15.0.0

- Прямой сбор видимых действий со стола без открытого LOG: Call, Raise, Bet, Check, Fold и отдельные изменения ставки без распознанного действия. Включите передачу данных в Windows.
- Во вкладке «Игроки» источник «Со стола» выбран по умолчанию. «Руки*» означают частичные наблюдения, а не завершённые истории; перезагрузка может разделить одну руку. Пропущенные действия не восстанавливаются. VPIP/PFR/3-bet/AF остаются в источнике «Полные руки».
- Действия сохраняются в APPDATA с привязкой к ID, подтверждением записи и защитой от повторной отправки. Очередь до 500 событий живёт до закрытия страницы. При скрытой вкладке сбор приостанавливается; переполнение явно показывается.
- Дополнительно открытый Session Log позволяет автоматически сохранять завершённые NL Hold’em руки с началом, концом, списком участников и блайндами. Неизвестные строки и неподдерживаемые типы игр не учитываются. Совпадающие стол и номер руки не дублируются при повторе и импорте CSV.
- Версия реально загруженного оверлея показана в заголовке. Строка «Сбор» показывает связь, очереди и результат сохранения.
- В Windows появились наблюдения со стола в профилях и вкладке текущих игроков. Кнопка «Открыть папку приложения» находится рядом с обновлениями на вкладке «Подключение и безопасность».

Обновите приложение через «Проверить обновления», перезагрузите расширение и страницу стола. Проверьте v15.0.0 в заголовке. Включите «Передавать данные» с кодом сопряжения. Для режима «Со стола» журнал можно закрыть.

Наблюдения со стола и полные руки намеренно не смешиваются. Это запись видимых данных, без игровых действий и доступа к скрытым API. Все сохранённые столы учитываются вместе; типы игр пока не разделены. Старые пропуски можно восстановить только из полного журнала/CSV.
