# PokerNow Analyst v8 — CFR+ sampling и Codex без API-ключа

Windows-приложение для **послематчевого анализа раздач**, статистики игроков PokerNow и учебного многоуличного GTO. Исходники Python 3.10+; автономного исполняемого `.exe` в архиве нет. Предыдущие функции v7, база SQLite и оверлей Opera v2 сохранены. Реальную работу в Opera/Windows ещё необходимо проверить на устройстве пользователя.

## Главное в v8

1. **Новый режим CFR+ `systematic`** для флопа и тёрна. Случайно смещённый систематический выбор пары приватных рук по весам совместимого диапазона: распределяет выборку ровнее, чем независимые случайные выборы. Вместо обещаний «истинного GTO» качество измеряется точным best response в той же небольшой абстрактной игре.
2. **Экспериментальный режим `paired`**: за эпоху обрабатывает каждую совместимую пару приватных рук, но только один возможный ранаут на пару. Лимит 16 совместимых пар. Это дороже на одну эпоху; **не гарантирует улучшение**. Нельзя сравнивать режимы только по итерациям без учёта `world_updates`.
3. **Сравнение v7/v8 в Windows-интерфейсе:** кнопка `Сравнить v7 / v8 · NashConv`, сравнивает старый `random` и новый `systematic` на трёх seed при равном количестве обработанных миров. Полный точный аудит отказоустойчиво ограничен по размеру задачи. Результат входит в экспорт JSON.
4. **Codex Analyst через аккаунт ChatGPT, без ключа OpenAI API.** Отдельная кнопка входа в Codex и кнопка `Разобрать офлайн GTO с Codex` на вкладке `AI-советник`. Python SDK `openai-codex` использует существующий ChatGPT-логин и поддерживает `login_chatgpt()`. Перед отправкой отчёта программа запрашивает согласие. Codex получает только *offline_gto* данные, без live-стола, имён игроков и персональных заметок. Сессия создаётся во временной пустой папке с режимом sandbox `read_only`; обращение к API расходует доступные лимиты Codex аккаунта ChatGPT.

## Установка (Windows)

1. Установи **Python 3.10+** (с Tkinter) с https://www.python.org/downloads/windows/ и включи Add to PATH.
2. Распакуй ZIP в отдельную папку. Перед обновлением можно сделать резервную копию `%APPDATA%\PokerNowAnalyst\history.sqlite3`. База хранится отдельно от папки приложения.
3. Запусти `START_WINDOWS.bat`. Математический движок и локальный анализ не требуют ключа или внешних зависимостей.
4. Чтобы включить Codex, запусти `INSTALL_CODEX_WINDOWS.bat` (нужен интернет; он установит официальный Python SDK). Можно выполнить вручную: `py -3 -m pip install openai-codex`.
5. Во вкладке **AI-советник** нажми `Войти в Codex через ChatGPT`. Заверши авторизацию в открывшемся браузере. **Не передавай пароль или токены приложению.** Если Codex уже авторизован на этом ПК, SDK обычно использует существующую авторизацию.
6. В одной из GTO-вкладок рассчитай **завершённую раздачу** по борду, диапазонам и ставкам. Затем перейди к **AI-советнику**, введи вопрос и нажми `Разобрать офлайн GTO с Codex`. Подтверди отправку данных. Полная проверка этого сетевого шага требует входа в аккаунт на Windows, поэтому здесь он проверен только с тестовым подставным SDK-клиентом.
7. При желании запусти `BUILD_EXE_WINDOWS.bat` для локальной сборки. **Сборка EXE на настоящем Windows, особенно с необязательным Codex SDK, не тестировалась; рекомендуется Python-запуск.**

## Результаты контрольного сравнения

Для воспроизводимого теста использованы банк 100, эффективный стек 80, размеры BET 50% банка, один рейз на улицу, итераций **650**, seed **9/21/37**, одинаковые диапазоны `AcQc,JsJh` / `KcQc,TsTd`. `systematic` и `random` обрабатывают одинаковые **650 миров на seed**. Чем меньше NashConv, тем лучше в *ограниченной учебной модели*.

| Начальный борд | Средний NashConv v7 random | Средний NashConv v8 systematic | Снижение |
|---|---:|---:|---:|
| `Ah Kd 7c 9s` (тёрн) | 23.5948 | 22.4182 | **5.0%** |
| `Ah Kd 7c` (флоп) | 52.2640 | 51.5942 | **1.3%** |

Отчёты: `examples/v8_sample_comparison.json` и `examples/v8_flop_comparison.json`. На отдельных seed результаты могут быть хуже: уменьшение NashConv **не гарантируется**. Флоп ещё содержит много необученных информационных состояний; измерения служат индикатором слабой сходимости, а не доказательством оптимальности. Для большего размера диапазонов аудит ограничен, а сравнение прерывается с объяснением причины вместо ложной метрики.

## Офлайн-тесты

```
py -3 -m unittest discover -s tests -v
```

В базовый проект включён набор модульных тестов, плюс проверки систематического и парного сэмплирования, точного аудита и Codex-адаптера. Реальная авторизация и сетевой ответ Codex не имитируются как состоявшиеся; без подключения они не проверены. Python SDK является **необязательной** зависимостью. AI-ответ может быть неточным: он не заменяет математический солвер.

## Ограничения

Модель — heads-up, 3–5 открытых карт, не более 2 сайзингов на улице, не более одного рейза, без префлопа, рейка, полноценного дерева 3-бетов/4-бетов и мультипотов. Для большой игры оптимальная стратегия не гарантирована; всё предназначено для **анализа завершённых раздач**, не для подсказок в реальном времени и не для автоматических действий в PokerNow.
